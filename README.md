lyris ✧

lyrics, but make them constellations.

lyris is a little lyric visualizer that turns words into stars.
It displays word-synced lyrics in a constellation-inspired layout, letting you watch songs unfold one word at a time.

made for the love of music, pretty visuals, and getting a little too attached to certain songs.

✧ features

- word-level lyric synchronization
- constellation-inspired lyric visualization
- live playback tracking
- minimal, immersive visuals
